# C4 model — Project 04

- **Context:** Customer support analyst or API client sends feedback to Sentiment Intelligence; dataset curator supplies authorized data.
- **Container:** FastAPI inference service, offline trainer, model artifact, optional enterprise gateway and observability.
- **Component:** Input validation → cached model loader → TF-IDF vectorizer → logistic regression → probability mapping.
- **Deployment:** Docker Desktop, Rancher Desktop, Podman Desktop, or a Kubernetes/OpenShift reference environment.

Editable Mermaid sources are under `diagrams/source/`. Production dependencies depicted in architecture views are aspirational until deployed and validated.
