# Dataset selection and licensing

- **Default lab:** small synthetic hand-authored positive/negative examples; no external downloads and **no real-world accuracy claims**.
- **Real evaluation candidates:** Stanford Sentiment Treebank (SST-2/GLUE) and IMDb reviews. Verify each dataset's actual license, provenance, redistribution conditions and allowed commercial uses before use.
- Split by source/customer/time where appropriate to avoid leakage; record language, dialect, class balance, privacy impact and evaluation provenance.
- Never commit private customer feedback or personal data. Store approved data in governed storage, not Git.
